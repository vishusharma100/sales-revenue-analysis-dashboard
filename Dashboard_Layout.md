# Power BI Dashboard Layout

## KPI Cards
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value

## Visuals
1. Line chart: Monthly Sales & Profit
2. Column chart: Sales by Category
3. Bar chart: Profit by Region
4. Bar chart: Top 10 Products by Sales
5. Donut chart: Sales by Customer Segment
6. Column chart: Sales by Payment Mode

## Slicers
- Order Date
- Region
- Category
- Customer Segment
- Payment Mode

## Data Import
1. Open Power BI Desktop.
2. Get Data → Text/CSV.
3. Select `data/sales_data.csv`.
4. Load the Sales table.
5. Add the DAX measures from `DAX_Measures.md`.
6. Build the visuals using the layout above.
